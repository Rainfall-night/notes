> **模板方法模式**定义了一个算法的骨架（流程），**将具体步骤延迟到子类中实现**。它的核心思想是==父类定义算法流程，子类实现具体步骤==。

## 实现方式
+ 定义模板抽象类，部分实现步骤由子类实现(**被abstract修饰的方法**)
~~~java
abstract class AbstractLoginTemplate {  
  
    protected String phoneNumber;  
    protected String password;  
    protected Integer verificationCode;  
  
    public AbstractLoginTemplate(String phoneNumber, String password) {  
        this.phoneNumber = phoneNumber;  
        this.password = password;  
    }  
  
    public AbstractLoginTemplate(String phoneNumber, Integer verificationCode) {  
        this.phoneNumber = phoneNumber;  
        this.verificationCode = verificationCode;  
    }  
  
    // 模板方法  
    public final void login() {  
        checkParams();  
        doLogin();  
        if (needLog()) log();  
        result();  
    }  

	//抽象方法子类必须实现，父类只用写方法名
    protected abstract void checkParams();  
  
    protected abstract void doLogin();  
  
    protected Boolean needLog(){  
        return true;  
    }  
  
    protected void log() {  
        System.out.println("记录登录日志...");  
    }  
  
    protected void result() {  
        System.out.println("返回登录结果");  
    }  
}
~~~
+ 子类继承并实现父类中定义的抽象方法
```java
class PasswordLogin extends AbstractLoginTemplate{  
	//参数传递顺序 实例对象 -》 子类构造函数 -》父类构造函数 -》 父类参数 —》子类继承使用
    public PasswordLogin(String phoneNumber, String password) {  
        super(phoneNumber, password);  
    }  
  
    @Override  
    protected void checkParams() {  
        System.out.println("手机号："+super.phoneNumber+"密码"+super.password);  
        System.out.println("密码登录，检查 账号--密码 ");  
    }  
  
    @Override  
    protected void doLogin() {  
        System.out.println("密码登录，执行登录--- ");  
    }  
}

class VerificationCodeLogin extends AbstractLoginTemplate{  
    public VerificationCodeLogin(String phoneNumber, Integer verificationCode){
        super(phoneNumber, verificationCode);  
    }  
  
    @Override  
    protected void checkParams() {  
  
        System.out.println("手机号："+super.phoneNumber+"验证码"+super.verificationCode);  
        System.out.println("验证码登录，检查 账号--验证码 ");  
    }  
  
    @Override  
    protected void doLogin() {  
        System.out.println("验证码登录，执行登录 ---- ");  
    }  
  
    @Override  
    protected Boolean needLog() {  
        return false;  
    }  
}
```
