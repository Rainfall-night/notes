> 工厂模式是一种创建型设计模式，它**定义一个对象创建接口**，并让其子类决定实例化哪个类；使用工厂模式的目的是将对象的创建与使用解耦；工厂模式分为三种，简单工厂、工厂方法和抽象工厂

## 工厂分类
### 1.简单工厂
+ **特点**：由一个工厂类，根据传入参数创建某个产品对象
+ **适用场景**：产品种类少，创建逻辑简单

#### 实现
+ 展示示例
~~~java
// 展示示例
interface Product {  
     void use();  
}

//被工厂模式解耦的对象
class Computer implements Product {  
  
    @Override  
    public void use() {  
        System.out.println("Computer use");  
    }  
  
}

//被工厂模式解耦的对象
class Phone implements Product {  
  
    @Override  
    public void use() {  
        System.out.println("Phone use");  
    }  
}

~~~

+ 简单工厂实现 + 使用
~~~java
//定义简单工厂类
class SimpleProductFactory {  
    public static Product create(String type){  
        if("phone".equalsIgnoreCase(type)){  
            return new Phone();  
        } else if ("computer".equalsIgnoreCase(type)) {  
            return new Computer();  
        }else {  
            throw new IllegalArgumentException("unknown product type: " + type);  
        }  
    }  
}

//使用简单工厂创建对象
System.out.println("==========简单工厂创建对象==========");  
Product simpleProduct1 = SimpleProductFactory.create("phone");  
Product simpleProduct2 = SimpleProductFactory.create("computer");  
simpleProduct1.use();  
simpleProduct2.use();
~~~

### 2.工厂方法
+ **特点**：每个对象都有对应的工厂类，遵循开闭原则(新增产品不改原代码，只需扩展)
+ **适用场景**：产品较多且变动频繁，产品创建过程复杂（如构造函数有依赖）

#### 实现
+ 展示示例
~~~java
// 展示示例
interface Product {  
     void use();  
}

//被工厂模式解耦的对象
class Computer implements Product {  
  
    @Override  
    public void use() {  
        System.out.println("Computer use");  
    }  
  
}

//被工厂模式解耦的对象
class Phone implements Product {  
  
    @Override  
    public void use() {  
        System.out.println("Phone use");  
    }  
}

~~~

+ 工厂方法模式定义 + 使用
~~~java
interface ProductFactory {  
    Product create();  
}

class PhoneFactory implements ProductFactory{  
    @Override  
    public Product create() {  
        return new Phone();  
    }  
}

class ComputerFactory implements ProductFactory {  
  
    @Override  
    public Product create() {  
        return new Computer();  
    }  
}

//工厂方法创建对象  
System.out.println("==========工厂方法创建对象==========");  
Product factoryProduct1 = new PhoneFactory().create();  
Product factoryProduct2 = new ComputerFactory().create();  
factoryProduct1.use();  
factoryProduct2.use();
~~~

#### 关于工厂方法的思考
> 工厂方法的引入是为了将类==对象的实例化与使用进行解耦==，但在使用过程中却发现虽然使用工厂方法模式解耦了要使用的对象的实例化与使用，但却又引入了工厂对象的实例化，导致了新的耦合(简单工厂没有这个问题)，所以需要再次对工厂方法实例化进行解耦

1. 使用工厂方法管理器对工厂方法实例化解耦
	+ 为了解耦引入新的耦合问题，再引入新的组件再次解耦，值得吗？
	+ 使用`Supplier<T>`供应器，在Map中保存工厂方法的创建逻辑，在真正需要创建时再使用supplier.get()创建实例(懒加载)
~~~java
class ProductFactoryManager {  
  
    //使用Supplier<T>供应器，在Map中保存工厂方法的创建逻辑，在真正需要创建时再使用supplier.get()创建实例 （懒加载）
    private static final Map<String, Supplier<ProductFactory>> promotionFactories = new HashMap<>();  
  
    static {  
        //ComputerFactory::new  --  lambda表达式保存工厂类创建逻辑  
        promotionFactories.put("computer",ComputerFactory::new);  
        promotionFactories.put("phone",PhoneFactory::new);  
    }  
    public static Product create(String productName) {  
        //返回创建的工厂类中创建的实例对象  
        return promotionFactories.get(productName).get().create();  
    }  
}
~~~




### 3.抽象工厂方法
+ **特点**：一次性创建多个“相关产品”（产品族），产品组之间保持一致性，防止“混搭”
+ **适用场景**：创建多个相关/相互依赖对象

#### 实现
+ 展示实例
~~~java
interface Menu {  
    void openMenu();  
}

interface Button {  
    void pressButton();  
}

class PCMenu implements Menu {  

    @Override  
    public void openMenu() {  
        System.out.println("显示PC风格菜单");  
    }  
}

class PCButton implements Button {  
  
    @Override  
    public void pressButton() {  
        System.out.println("按下PC风格按钮");  
    }  
}

class MobileMenu implements Menu {  
  
    @Override  
    public void openMenu() {  
        System.out.println("显示手机风格菜单");  
    }  
}

class MobileButton  implements Button {  
    @Override  
    public void pressButton() {  
        System.out.println("按下手机风格按钮");  
    }  
}
~~~

+ 抽象工厂模式实现 + 使用
~~~java
interface GameUIFactory {  
  
    Menu createMenu();  
  
    Button createButton();  
}

class PCGameUI implements  GameUIFactory{  

    @Override  
    public Menu createMenu() {  
        return new PCMenu();  
    }  
  
    @Override  
    public Button createButton() {  
        return new PCButton();  
    }  
}

class MobileGameUI implements GameUIFactory{  
  
    @Override  
    public Menu createMenu() {  
        return new MobileMenu();  
    }  
  
    @Override  
    public Button createButton() {  
        return new MobileButton();  
    }  
}

System.out.println("==========抽象工厂创建对象==========");  
PCGameUI pcGameUI = new PCGameUI();  
Menu pcGameMenu = pcGameUI.createMenu();  
Button pcGameButton = pcGameUI.createButton();  
  
pcGameMenu.openMenu();  
pcGameButton.pressButton();  
  
MobileGameUI mobileGameUI = new MobileGameUI();  
Menu mobileGameMenu = mobileGameUI.createMenu();  
Button mobileGameButton = mobileGameUI.createButton();  
  
mobileGameMenu.openMenu();  
mobileGameButton.pressButton();
