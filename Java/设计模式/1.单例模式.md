> 单例模式的目的是让一个类在整个系统中只有一个实例，并且提供全局访问点

## 适用场景
+ 配置管理类
+ 日志类
+ 数据库连接池
+ 缓存、线程池
+ 工具类(唯一ID生成器之类的)

# 单例模式构建要点
1. **私有化构造方法**  ----  防止外部new出对象
2. **持有唯一私例**  ----  类内部保存一个static对象
3. **提供公共访问方法**  ----  只能通过==getinstance()==方法获取唯一实例对象

## 实现方式
### 1.饿汉式
> 类加载时就创了唯一实例，并且线程安全(类加载过程天然线程安全)，但加载类时就创建了其实例对象，内存开销较大
```java
public class HungryModel {  
    private static final HungryModel instance = new HungryModel();  
  
    private HungryModel(){};  
  
    public static HungryModel getInstance() {  
        return instance;  
    }  
}
```

### 2.懒汉式
> 只有在调用getInstance()方法时才会创建实例对象(懒加载)，但多线程任务时，可能创建多个实例对象，线程不安全
```java
// 懒汉模式(线程不安全)  
public class LazyModel {  
  
    private static LazyModel instance;  
  
    //私有化构造方法，放置外部new出来  
    private LazyModel() {}  
  
    public static LazyModel getInstance(){  
        if (instance == null){  
            instance = new LazyModel();  
        }  
        return instance;  
    }  
}
```

### 3.懒汉模式配合synchronized
> 配合synchronized关键字，保证在getInstance()方法时仅有一个线程判断是否创建，保证线程安全，但其余线程等待，性能较差
```java
public class LazyModel {  
  
    private static LazyModel instance;  
  
    //私有化构造方法，放置外部new出来  
    private LazyModel() {}  
  
    public static synchronized LazyModel getInstance(){  
        if (instance == null){  
            instance = new LazyModel();  
        }  
        return instance;  
    }  
}
```

### 4.双重检查锁(DCL)
> 外层if检查保证在已经创建唯一实例对象后其余线程不再进入同步块，内部if检查确保值初始化一次，volatile保证指令重排序
```java
public class DoubleSyncModel {  
    private static  volatile DoubleSyncModel instance;  
  
    private DoubleSyncModel() {}  
  
    public static  DoubleSyncModel getInstance(){  
        if(instance == null){  
            synchronized(DoubleSyncModel.class){  
                if(instance == null){  
                    instance = new DoubleSyncModel();  
                }  
            }  
        }  
        return instance;  
    }  
}
```

### 5.静态内部类
> 在单例类中引入一个内部类，在调用getInstance()时该类才会被启用加载，由于jvm的类加载机制，保证线程安全和懒加载
```java
public class StaticClassModel {  
    private StaticClassModel() {}  
  
    private class InstanceHolder {  
        private static final StaticClassModel INSTANCE = new StaticClassModel();  
    }  
  
    public static StaticClassModel getInstance(){  
        return InstanceHolder.INSTANCE;  
    }  
}
```

### 6.枚举单例
>Java 枚举类在 JVM 层面保证单例，自动防止反射攻击、反序列化攻击（因为 JVM 保证 enum 唯一性），不支持延迟加载（和饿汉类似）
~~~java
public enum EnumModel {  
    INSTANCE;  
  
    public void doSomething() {  
        System.out.println("doSomething");  
    }  
}
~~~
