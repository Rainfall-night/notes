> 观察者模式（Observer Pattern），又称为发布-订阅模式（Publish-Subscribe Pattern），定义了对象之间**一对多**的依赖关系。当一个对象（称为**主题**或**发布者**）的状态发生改变时，所有依赖于它的对象（称为**观察者**或**订阅者**）都会得到通知，并自动进行更新。
> 这种模式的核心思想是**解耦**。发布者和订阅者之间没有紧密的耦合关系。发布者只负责通知，而不需要知道具体哪个观察者是谁、有多少个，以及它们将如何处理这个通知。观察者也只关心它所订阅的主题，而不关心其他观察者。

# 主要角色

| 角色    | 功能                                                                                                                                        |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 抽象主题  | + 定义了一个用于管理和通知观察者的接口。<br>+ 通常包含一个列表（或集合）来存**储所有的观察者对象**。<br>+  提供方法来**添加**（`attach`）、**删除**（`detach`）和**通知**（`notify`）观察者<br>+ 抽象主题角色可以没有 |
| 具体主题  | + 实现抽象主题                                                                                                                                  |
| 抽象观察者 | + 定义基本的观察者更新接口，观察者通过该接口被主题通知<br>                                                                                                          |
| 具体观察者 | + 实现了抽象观察者接口，完成更新接口  <br>+ 将观察者注册到具体主题上 <br>+ 当收到主题的通知时，执行自己的更新逻辑                                                                         |

# 优缺点
**优点**：
- **松耦合**：发布者和订阅者之间没有直接依赖，可以独立开发和修改。
- **灵活性和可扩展性**：可以随时增加或移除观察者，而无需修改发布者的代码。
- **支持广播**：主题可以轻松地向所有观察者发送通知，实现一对多的广播通信。
- 
**缺点**：
- **性能问题**：如果观察者数量非常庞大，每次通知都会遍历整个列表，可能会导致性能下降。
- **循环依赖**：如果观察者和主题之间存在复杂的相互通知机制，可能会导致死循环。
- **执行顺序不确定**：通常无法保证观察者收到通知的顺序。

# 实现
> 本案例以股票交易为背景，设计了两种观察者，一种为激进股票买家，当股票价格与上次交易价格的涨幅超过10%时会考虑加仓；一种为保守型股票买家，当股票价格与上次交易价格的跌幅查过5%时会考虑减仓

```java
// 订阅主题，模拟股票价格变动
class Stock {  
  
    // 当前股票价格  
    private BigDecimal price;  
  
    //观察者列表  
    private List<Investor> investors;  
  
    public Stock() {  
        investors = new ArrayList<>();  
    }  
  
    // 设置价格  
    public void setPrice(BigDecimal price) {  
        this.price = price;  
        notifyInvestor();  
    }  
  
    // 观察者订阅主题接口
    public void registerInvestor(Investor investor) {  
        this.investors.add(investor);  
    }  
  
    // 通知订阅者  
    public void notifyInvestor() {  
        for (Investor investor : investors) {  
            investor.update(this.price);  
        }  
    }  
}

// 抽象观察者，仅维护更新观察者的接口
interface Investor {  
    void update(BigDecimal price);  
}

//具体观察者，此处为保守股票买家
class ConservativeInvestor implements Investor {  
  
    private BigDecimal lastPrice;     // 存储上次交易时的价格
    private Stock stock;              // 订阅的主题
  
    public ConservativeInvestor(Stock stock) {  // 初始化时就订阅主题,此处非必要，可根据看v提情况设置什么时候订阅
        this.stock = stock;  
        stock.registerInvestor(this);  
    }  
  
    @Override  
    public void update(BigDecimal price) {  
        // 上次价格为空，说明时第一次运行，不用看涨幅  
        if (lastPrice == null) {  
            lastPrice = price;  
            return;        }  
        // 计算涨幅  
        //                           计算差价              计算除法差值（除数，精度，舍入方式）  
        BigDecimal increment = price.subtract(lastPrice).divide(lastPrice, 4, RoundingMode.HALF_UP);  
        System.out.println(increment);  
  
        BigDecimal threshold = new BigDecimal("-0.05");     // 能承受的幅度  
        if (increment.compareTo(threshold) <= 0) {  
            System.out.println("保守型股民：股票价格大幅下跌（" + increment.multiply(new BigDecimal(100)) + "%），考虑卖出。");  
            lastPrice = price;  
        }  
  
    }  
}

// 具体观察者，激进型股票买家
class AggressiveInvestor implements Investor {  
  
    private BigDecimal lastPrice;  
    private Stock stock;  
  
    public AggressiveInvestor(Stock stock) {  
        this.stock = stock;  
        stock.registerInvestor(this);  
    }  
  
    @Override  
    public void update(BigDecimal price) {  
        // 上次价格为空，说明时第一次运行，不用看涨幅  
        if (lastPrice == null) {  
            lastPrice = price;  
            return;        }  
  
        // 计算涨幅  
        BigDecimal increment = price.subtract(lastPrice).divide(lastPrice, 4, RoundingMode.HALF_UP);  
  
        BigDecimal threshold = new BigDecimal("0.1");     // 能承受的幅度  
        if (increment.compareTo(threshold) >= 0) {  
            System.out.println("保守型股民：股票价格大幅下跌（" + increment.multiply(new BigDecimal(100)) + "%），考虑卖出。");  
            lastPrice = price;  
        }  
  
    }  
}


// 使用主类：
class Main {  
  
    public static void main(String[] args) throws InterruptedException {  
        // 创建主题  
        Stock stock = new Stock();  
  
        //创建观察者  
        ConservativeInvestor conservativeInvestor1 = new ConservativeInvestor(stock);  
        ConservativeInvestor conservativeInvestor2 = new ConservativeInvestor(stock);  
  
        AggressiveInvestor aggressiveInvestor1 = new AggressiveInvestor(stock);  
        AggressiveInvestor aggressiveInvestor2 = new AggressiveInvestor(stock);  
  
        stock.setPrice(BigDecimal.valueOf(500.00));     //设置初始价格  
  
        Thread.sleep(5000);  
  
        stock.setPrice(BigDecimal.valueOf(560.00));  
  
        Thread.sleep(5000);  
  
        stock.setPrice(BigDecimal.valueOf(500.00));  
  
    }  
}
```
