> 装饰器模式**动态地给一个对象添加额外的职责**，提供比继承更灵活的扩展方式(只做扩展不做权限访问,与代理模式区别)

# 装饰器模式的主要构成角色
| 角色                    | 说明                                 |
| --------------------- | ---------------------------------- |
| **Component**         | 定义抽象接口，可以是抽象类或接口                   |
| **ConcreteComponent** | 被装饰的具体实现类                          |
| **Decorator**         | 持有Component引用，实现Component接口（抽象装饰器） |
| **ConcreteDecorator** | 具体装饰器，添加额外功能                       |

# 实现
```java
//抽象接口
interface Text {  
    String format();  
}

// 被装饰的具体实现类
class PlainText implements Text{  
  
    private String context;  
  
    public PlainText(String context) {  
        this.context = context;  
    }  
  
    @Override  
    public String format() {  
        return context;  
    }  
}

//抽象装饰器，实现了抽象接口，但具体实现要看其子类
abstract class TextDecorate implements Text {  

	// protexted控制其子类可以访问该对象
	// 抽象接口作为内部参数，以便对其进行功能增强
    protected Text text;  
  
    public TextDecorate(Text text) {  
        this.text = text;  
    }  
  
    public abstract String format();  
}

// 具体装饰实现
class UpperCaseDecorate extends TextDecorate{  
  
  
    public UpperCaseDecorate(Text text) {  
        super(text);  
    }  
  
    @Override  
    public String format() {  
        return text.format().toUpperCase();  // 大写字母
    }  
}

class BorderDecorate extends TextDecorate {  
  
    public BorderDecorate(Text text) {  
        super(text);  
    }  
  
    @Override  
    public String format() {  // 给字符串加边框
        String content = text.format();  //保存原始字符串
        int length = content.length();  //保存原始大小
        String border = "*".repeat(length);  //上下边框长度
        content = border + "\n" + content + "\n" + border;  //先加上下边框
        String[] lines = content.split("\n");  
        String result = (String)Arrays.stream(lines)  //对每行处理
                .map(line -> line = "*" + line + " ".repeat(length - line.length()) + "*" + "\n")  
                .collect(Collectors.joining());  
  
        return result;  
  
    }  
}

class LineNumberDecorate extends TextDecorate {  
  
    public LineNumberDecorate(Text text) {  
        super(text);  
    }  
  
    @Override  
    public String format() {  //对字符串加行号
        String[] lines = text.format().split("\n");  
  
        String result = IntStream.range(0, lines.length)  
                .mapToObj(i -> (i + 1) + ": " + lines[i] + "\n")  
                .collect(Collectors.joining());  
        return result;  
    }  
}
```
