> 代理模式是为其他对象提供一种代理以**控制对这个对象的访问**。其原始目的仅是提供对原始对象的访问控制，而经常使用的"动态增强"只是在访问控制时衍生出来的附加目的，它完全可以不实现“动态增强”。

# 代理模式结构
| 角色            | 描述                      |
| ------------- | ----------------------- |
| `Subject`     | 抽象接口，定义目标对象和代理对象的共同接口   |
| `RealSubject` | 真实对象，包含核心业务逻辑           |
| `Proxy`       | 代理对象，控制对真实对象的访问，可添加附加逻辑 |

# 代理模式分类
## 1.静态代理
> 在编译时实现，手动编写代理类逻辑，编译时确定代理关系
+ 实现：
```java
// 抽象接口
interface UserService {  
  
    void login();  
  
    void userList();  
}

// 真实对象
class UserServiceImpl implements UserService{  
  
    private String loginParam;  
  
    public  UserServiceImpl(String loginParam) {  
        this.loginParam = loginParam;  
    }  
  
    @Override  
    public void login() {  
        System.out.println("login");  
    }  
  
    @Override  
    public void userList() {  
        System.out.println("userList");  
    }  
}

//代理对象
class UserServiceProxy implements UserService {  
  
    private String loginParam;  
  
    private UserService realService;  
  
    public UserServiceProxy(String loginParam) {  
        this.loginParam = loginParam;  
        this.realService = new UserServiceImpl(this.loginParam);  
    }  
  
  
    @Override  
    public void login() {  
        System.out.println("proxy start");  
        realService.login();  
        System.out.println("proxy end");  
    }  
  
    @Override  
    public void userList() {  
        System.out.println("proxy start");  
        realService.userList();  
        System.out.println("proxy end");  
    }  
}

// 使用
class Main {  
    public static void main(String[] args) {  
        UserService serviceProxy = new UserServiceProxy("loginParam");  
  
        serviceProxy.login();  
  
        System.out.println("______________________");  
  
        serviceProxy.userList();  
    }  
}
```


## 2.动态代理
### JDK动态代理
> 要求目标对象必须实现接口，JDK内置，无需额外依赖

+ 实现
```java
// 抽象接口
interface UserService {  
  
    void login();  
  
    void userList();  
}

// 具体实现
class UserServiceImpl implements UserService {  
  
    private String loginParam;  
  
    public  UserServiceImpl(String loginParam) {  
        this.loginParam = loginParam;  
    }  
  
    @Override  
    public void login() {  
        System.out.println("login");  
    }  
  
    @Override  
    public void userList() {  
        System.out.println("userList");  
    }  
}

// 代理策略
class ProxyHandler implements InvocationHandler {  
  
    private Object target;  
  
    public ProxyHandler(Object target) {  
        this.target = target;  
    }  
  
    @Override  
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {  

		//此处提供访问控制、动态增强之类的都可以
        System.out.println("proxy start");  
        Object result = method.invoke(target, args);  
        System.out.println("proxy end");  
  
        return result;  
    }  
}

// 使用
class Main {  
  
    public static void main(String[] args) {  
  
        UserServiceImpl target = new UserServiceImpl("loginParam");  
  
        System.out.println("注册代理处理器写法");  
        UserService userProxy = (UserService) Proxy.newProxyInstance(  
                target.getClass().getClassLoader(),  
                target.getClass().getInterfaces(),  
                new ProxyHandler(target)  
        );  
  
        userProxy.login();  
        userProxy.userList();  
  
        System.out.println("lambda表达式匿名内部类代理处理器写法");  
  
        UserService userProxy1 =(UserService) Proxy.newProxyInstance(  
                target.getClass().getClassLoader(),  
                target.getClass().getInterfaces(),  
                (obj, method, argss) -> {  
                    System.out.println("proxy start");  
                    Object result = method.invoke(target, argss);  
                    System.out.println("proxy end");  
                    return result;  
                });  
  
        userProxy1.login();  
        userProxy1.userList();  
    }
```

### CGLIB动态代理
> 可代理普通类（该类**需要具备无参构造函数**），需要**添加CGLIB依赖**，生成子类覆盖方法，

+ 实现
```java
// 普通类
class UserService {  
    private String loginParam;  
  
    public UserService() {}  
  
    public  UserService(String loginParam) {  
        this.loginParam = loginParam;  
    }  
  
  
    public void login() {  
        System.out.println("login");  
    }  
  
  
    public void userList() {  
        System.out.println("userList");  
    }  
  
}

// 代理策略
class ProductInterceptor implements MethodInterceptor {  
    @Override  
    public Object intercept(Object obj, Method method, Object[] args, MethodProxy proxy) throws Throwable {  
        System.out.println("proxy start");  
        Object result = proxy.invokeSuper(obj, args);  
        System.out.println("proxy end");  
        return result;  
    }  
}

// 使用
class Main {  
    public static void main(String[] args) {  
  
  
        UserService target = new UserService("loginParam");  
  
        Enhancer enhancer = new Enhancer();  
        enhancer.setSuperclass(target.getClass());  
        enhancer.setCallback(new ProductInterceptor());  
        UserService userProxy = (UserService)enhancer.create();  
  
        userProxy.login();  
        userProxy.userList();  
  
  
    }  
}
```
