> 策略模式定义了==一系列算法或行为==，把它们一个个封装起来，==并且可以互相替换==，使得算法的变化独立于使用算法的客户端。

## 实现方式
 +  策略接口+策略实现
~~~java
// 案例为折扣使用策略
interface PromotionStrategy {  
    double calculatePrice(double originalPrice);  
}

//无折扣策略
class NoPromotionStrategy implements PromotionStrategy {  
    @Override  
    public double calculatePrice(double originalPrice) {  
        return originalPrice;  
    }  
}

//满减折扣策略
class FullReductionStrategy implements PromotionStrategy {  
    @Override  
    public double calculatePrice(double originalPrice) {  
        if(originalPrice >= 100){  
            return originalPrice - 20;  
        }  
        return originalPrice;  
    }  
}

//打折折扣策略
class DiscountStrategy implements PromotionStrategy {  
    @Override  
    public double calculatePrice(double originalPrice) {  
        return originalPrice * 0.9;  
    }  
}

~~~
+ 策略使用上下文 + 策略使用
~~~java
//策略使用上下文
class ContextStrategy {  
    private PromotionStrategy promotion;  

	//构造函数初始化传入折扣策略
    public ContextStrategy(PromotionStrategy promotion) {  
        this.promotion = promotion;  
    }  

	//计算折扣后价格
    public double getFinalPrice(double originalPrice){  
        return promotion.calculatePrice(originalPrice);  
    }  
}


double originalPrice = 120;          // 初始价格


//这里使用了工厂方法模式+懒加载的方式获取策略实例
ContextStrategy strategy1 = new ContextStrategy(PromotionFactoryManager.getPromotion("fullReduction"));  
ContextStrategy strategy2 = new ContextStrategy(PromotionFactoryManager.getPromotion("discount"));  
ContextStrategy strategy3 = new ContextStrategy(PromotionFactoryManager.getPromotion("noPromotion"));  
  
System.out.println("满减折扣后价格："+strategy1.getFinalPrice(originalPrice));  
System.out.println("九折折扣后价格："+strategy2.getFinalPrice(originalPrice));  
System.out.println("没有折扣后价格："+strategy3.getFinalPrice(originalPrice));
~~~
