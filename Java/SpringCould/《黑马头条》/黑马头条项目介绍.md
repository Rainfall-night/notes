项目介绍：
	黑马头条项目是一个新闻类App的后端项目，基于SpringCloud框架实现，提供了普通用户、内容创作者及系统管理员三个客户端的功能实现
项目技术：
	SpringCloud、SpringBoot、MyBatis/MyBatisPlus、MySQL、Redis、MongoDB、Kafka、ElasticSearch、XXL-JOB、MinIO
项目描述：
1. 使用FreeMarker模板引擎构建新闻内容的页面，将新闻内容作为静态资源展示在页面内；使用MinIO分布式文件系统存储FreeMarker渲染而成的HTML页面，并提供对外资源访问
2. 使用Redis作为缓存队列，实现审核任务的延期定时执行，并对文章审核任务进行削峰
3. 使用kafka作为消息中间件，在用户端与创作者端进行消息传递，实现文章商下架功能
4. 使用Elestricsearch引擎实现文章搜索功能，并使用MongoDB存储用户搜索历史数据
5. 基于Redis对用户行为进行记录，并对用户行为聚合并回显
6. 使用kafka流式计算对热点文章进行计算，实时计算热点文章，并使用XXL-JOB任务调度器对计算任务进行调度
