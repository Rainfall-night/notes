> 保护性暂停模式是一种线程间通信的同步模式，**当条件不满足时，线程暂时挂起（等待）**，直到条件满足后被唤醒继续执行。

# 核心要点
|要素|说明|
|---|---|
|**Guarded Object**|受保护的对象，包含被等待的结果（如您的`GuardedObject<T>`类）|
|**条件判断**|通过循环检查条件（如`while (response == null)`）|
|**等待/通知机制**|使用`wait()`/`notifyAll()`（或`Condition`）实现线程挂起与唤醒|
|**超时控制**|避免无限等待（如您的`timeout`参数）|
## **适用场景**

- 一个线程需要等待另一个线程的结果
- 异步任务的结果获取
- 生产者-消费者问题的变种

# 使用案例

```java
// 受保护对象
class GuardedObject <T> {  
  
    private T response;  
  
    //产生结果  
    public synchronized void setResponse(T response) {  
        this.response = response;  
        this.notifyAll();  // 唤醒所有挂起的线程
    }  
  
    //获取结果(最大等待时间)  
    public synchronized T getResponse(long timeout) {  
  
        //记录开始时间  
        long start = System.currentTimeMillis();  
        //记录已经等待的时间  
        long passTime = 0;  
  
        while (response == null) { 
	        // 还要等待的时间 
            long waitTime = timeout - passTime;  
            //经历的时间超过了最大等待时间  
            if (waitTime <= 0) {  
                break;  
            }  
            //未产生结果  
            try {  
                log.info("waitTime:{}", waitTime);  
                this.wait(waitTime);  
            } catch (InterruptedException e) {  
                throw new RuntimeException(e);  
            }  
  
            passTime = System.currentTimeMillis() - start;  
        }  
  
        return response;  
    }  
}

// 使用案例
class SmsExample {  
  
    //模拟场景，线程1等待线程2给的结果  
    public static void main(String[] args) throws InterruptedException {  
        ArrayList<String> list = new ArrayList<>();  
        list.add("test001");  
        list.add("test002");  
        list.add("test003");  
  
        GuardedObject<List<String>> go = new GuardedObject<>();  
  
        new Thread(()->{  
  
            log.info("t1开始");  
            List response;  
            Optional.ofNullable(response = go.getResponse(2000))  
                    .ifPresentOrElse(r ->{  
                        log.info("t1接收到回应：{}",response);  
                    },()->{  
                        log.error("t1未接收到回应");  
                    });  
  
        },"t1").start();  
  
        // Thread.sleep(5000);  
  
        new Thread(()->{  
            log.info("t2开始");  
            go.setResponse(list);  
            log.info("t2结束");  
        },"t2").start();  
    }  
}
```
