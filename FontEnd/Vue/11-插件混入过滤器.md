# 插件 / 混入 / 过滤器

> 三者都是**复用逻辑**的方式，但作用层级不同

---

## 一、Vue.use() — 插件（全局生效）

`Vue.use()` 会自动调用插件的 `install` 方法，传入 Vue 构造函数。

### 自定义插件示例

```js
// my-plugin.js
export default {
    install(Vue, options) {
        // ① 注册全局组件
        Vue.component('my-button', { template: '<button>全局按钮</button>' })

        // ② 挂原型方法
        Vue.prototype.$alert = (msg) => window.alert(msg)

        // ③ 注册全局指令
        Vue.directive('focus', { inserted(el) { el.focus() } })

        // ④ 注册全局混入
        Vue.mixin({ created() { console.log('每个组件创建时都打印') } })
    }
}
```

```js
// main.js
import MyPlugin from './my-plugin'
Vue.use(MyPlugin, { theme: 'dark' })   // options → install 的第二个参数
```

### 本项目实际

```js
// main.js
Vue.use(ElementUI, { locale })
```

ElementUI 的 `install` 做了两件事：
1. 全局注册所有 `el-xxx` 组件
2. 在 `Vue.prototype` 上挂 `$message`、`$notify` 等

> `Vue.use()` = 给 Vue 加功能的统一入口，比散落在 `main.js` 里到处 `Vue.xxx` 要整洁。

## 二、mixin — 混入（多组件共享逻辑）

把公共的生命周期 + methods + data 注入到多个组件中，避免复制粘贴。

### 通用列表 mixin 示例

```js
// mixins/pagination.js
export default {
    data() {
        return {
            listData: [],
            totalCount: 0,
            listLoading: false,
            queryParams: { pageIndex: 1, pageSize: 50 }
        }
    },
    methods: {
        fetchData() {
            this.listLoading = true
            getList(this.queryParams).then(res => {
                this.listData = res.Data.Items
                this.totalCount = res.Data.TotalCount
                this.listLoading = false
            })
        },
        handleSearch() {
            this.queryParams.pageIndex = 1
            this.fetchData()
        }
    }
}
```

```js
// 在列表页中使用
import paginationMixin from '@/mixins/pagination'
export default {
    mixins: [paginationMixin],
    // 自动拥有 listData、totalCount、fetchData、handleSearch
    mounted() { this.fetchData() }
}
```

### 本项目实际

```js
// layout/mixin/ResizeHandler.js
export default {
    beforeMount() {
        window.addEventListener('resize', this.$_resizeHandler)
    },
    beforeDestroy() {
        window.removeEventListener('resize', this.$_resizeHandler)
    },
    methods: {
        $_resizeHandler() { /* 窗口缩放处理 */ }
    }
}
```

```js
// layout/index.vue
import ResizeMixin from './mixin/ResizeHandler'
export default {
    mixins: [ResizeMixin]  // Layout 自动拥有 resize 处理能力
}
```

### 冲突处理规则

mixin 和组件有同名属性时，**分两类处理**：

| 冲突类型 | 规则 | 谁赢 |
|------|------|:--:|
| **生命周期钩子**（mounted、created等） | 合并为数组，都执行 | mixin 先，组件后 |
| **methods / computed / data 属性** | 同名覆盖 | 组件覆盖 mixin |
| **watch** | 合并为数组，都执行 | mixin 先，组件后 |

#### 完整示例

```js
const myMixin = {
    data() { return { a: 1, x: 'mixin版' } },
    methods: {
        handleClick() { console.log('mixin的') }
    },
    mounted() {
        console.log('mixin的mounted')
    }
}

export default {
    mixins: [myMixin],
    data() { return { b: 2, x: '组件版' } },
    methods: {
        handleClick() { console.log('组件的') }
    },
    mounted() {
        console.log('组件的mounted')
    }
}
```

运行结果：

```
this.a  → 1                    // data 合并（不冲突则合并）
this.b  → 2                    // data 合并
this.x  → '组件版'              // data 同名 → 组件覆盖 mixin
this.handleClick() → '组件的'   // methods 同名 → 组件覆盖 mixin

// mounted 输出顺序：
// ① mixin的mounted
// ② 组件的mounted              // 生命周期 → 都执行！
```

#### 规则速记

| mixin 有 | 组件也有 | 结果 |
|------|------|------|
| `data: { a: 1 }` | `data: { b: 2 }` | 合并 `{ a: 1, b: 2 }` |
| `data: { x: 1 }` | `data: { x: 2 }` | **组件覆盖** → `x: 2` |
| `computed: { c(){} }` | `computed: { c(){} }` | **组件覆盖** mixin |
| `methods: { fn() }` | `methods: { fn() }` | **组件覆盖** mixin |
| `mounted()` | `mounted()` | **都执行**，mixin 先 |
| `created()` | `created()` | **都执行**，mixin 先 |
| `watch: { a(){} }` | `watch: { a(){} }` | **都执行**，mixin 先 |

> **一句话：钩子叠加，属性覆盖。**

## 三、filter — 过滤器（格式化显示）

用于 `{{ }}` 和 `v-bind` 中的简单格式化。

### 通用 filter 示例

```js
filters: {
    // 日期格式化
    formatDate(val) {
        if (!val) return '-'
        const d = new Date(val)
        return `${d.getFullYear()}-${String(d.getMonth()+1).padStart(2,'0')}-${String(d.getDate()).padStart(2,'0')}`
    },

    // 金额格式化
    formatMoney(val) {
        return '¥' + Number(val).toFixed(2).replace(/\d(?=(\d{3})+\.)/g, '$&,')
    },

    // 文本截断
    truncate(val, len = 10) {
        if (!val) return ''
        return val.length > len ? val.slice(0, len) + '...' : val
    }
}
```

```vue
<span>{{ row.CreateTime | formatDate }}</span>       <!-- 2024-12-03 -->
<span>{{ row.Price | formatMoney }}</span>           <!-- ¥1,234.56 -->
<span>{{ row.Remark | truncate(20) }}</span>         <!-- 这是一段很长很长的... -->
```

### 本项目实际

```js
// processingindex.vue
filters: {
    statusFilter(status) {
        const statusMap = { published: 'success', draft: 'gray', deleted: 'danger' }
        return statusMap[status]
    }
}
```

```vue
{{ status | statusFilter }}
```

> ⚠️ Vue 3 已移除 filter，建议用 `computed` 或 `methods` 替代。

## 四、三者对比

| | 作用层级 | 用途 | 本项目例子 |
|------|------|------|------|
| `Vue.use()` | 全局 | 安装插件 | `Vue.use(ElementUI)` |
| `mixin` | 多组件共享 | 抽取重复代码 | `ResizeHandler` |
| `filter` | 模板内 | 格式化显示 | `statusFilter` |
