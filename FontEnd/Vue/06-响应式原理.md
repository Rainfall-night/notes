# 响应式原理：data、computed、watch

> 基于 MES 前端项目 `STwebsiteFrontEnd_V1` 的实际代码

---

## 一、data — 原始数据，变就重渲染

```js
// TEST_LIV/index.vue
data() {
    return {
        listData: [],        // 变了 → 表格自动刷新
        totalCount: 0,       // 变了 → 分页自动刷新
        listLoading: false   // 变了 → loading 动画自动切换
    }
}
```

`data` 里的所有属性都会被 Vue 用 `Object.defineProperty` 拦截。一旦赋值，自动通知依赖者（模板中用到它的地方）重新渲染。

> `data` 必须是**函数**（`data() { return {} }`），不能是对象。因为组件可能被多次复用，每个实例需要一份独立的数据拷贝。详见 [[03-单文件组件#四、export default 组件选项完整清单|组件选项清单]]。

```js
// 赋值即刷新
this.listData = response.Data.Items
```

## 二、computed — 计算属性，有缓存

```js
// TEST_LIV/index.vue
computed: {
    rules() {
        return { TAT: [{ pattern: /^\d+/, message: '非负数字' }] }
    },
    pickerOptions() {
        return {
            shortcuts: [
                { text: '最近一周', onClick: ... },
                { text: '最近一个月', onClick: ... }
            ]
        }
    }
}
```

**有缓存**：依赖的 data 不变就**不重算**，直接返回上次结果。

```js
// 模板中用多少次都不怕，只算一次
:shortcuts="pickerOptions.shortcuts"   ← 取值，不重算
:shortcuts="pickerOptions.shortcuts"   ← 取值，不重算
```

### 与 methods 的区别

```js
methods: {
    getRules() { return { TAT: [...] } }  // ← 每次模板访问都执行
}
computed: {
    rules() { return { TAT: [...] } }     // ← 依赖不变就缓存
}
```

## 三、watch — 监听变化，做副作用

```js
// TEST_LIV/index.vue
watch: {
    pickerValue(newValue) {
        // 日期选择器变了 → 同步到 queryParams
        this.queryParams.dateRange = newValue.join('~')
    },
    selectedState: {
        handler(newValue) {
            this.queryParams.state = 0
            newValue.forEach(v => this.queryParams.state += Number(v))
        },
        immediate: true    // ← 初始值也触发一次
    },
    SelectedPackMode(newValue) {
        this.queryParams.PackMode = newValue ? newValue.toString() : ''
    }
}
```

**不做计算**，做"副作用"——一个数据变了，去改另一个数据、调 API、存 localStorage。

> `immediate: true`：组件初始化时也立即执行一次 handler，不只是等数据变化。这是 watch 独有的能力。

## 四、三者对比

| | data | computed | watch |
|------|------|------|------|
| 本质 | 原始数据源 | 基于 data 的**派生值** | 数据变化时的**回调** |
| 缓存 | ❌ 无 | ✅ 依赖不变就不重算 | ❌ 每次都执行 |
| 赋值 | ✅ `this.xxx = val` | ❌ 不能赋值 | ❌ 不是用来赋值的 |
| 异步 | ❌ | ❌ 不支持 async | ✅ 可以做异步操作 |
| 模板中用 | ✅ | ✅ | ❌ |
| 典型场景 | 存储数据 | 格式化、过滤、配置项 | 同步两个数据、调 API |

> 这三者都是 `export default {}` 中的顶级选项，详见 [[03-单文件组件#四、export default 组件选项完整清单|组件选项完整清单]]。

## 五、本项目实际速查

| 代码 | 类型 | 做了什么 |
|------|------|------|
| `listData: []` | data | 表格数据源 |
| `totalCount: 0` | data | 分页总数 |
| `tableList: [...]` | data | 列可见性配置 |
| `rules()` | computed | 表单校验规则 |
| `pickerOptions()` | computed | 日期快捷键配置 |
| `watch pickerValue` | watch | 日期 → queryParams |
| `watch selectedState` | watch | 状态位运算同步（`immediate`） |
| `watch SelectedPackMode` | watch | 封装形式 → queryParams |

## 七、Vue.observable — 让任意对象变成响应式（Vue 2.6+）

### 它解决什么问题？

正常情况下只有 `data()` 返回的对象才是响应式的。如果你有一个**独立于组件**的对象，想让它也能触发视图更新怎么办？

```js
// 普通对象 — 改了视图不会更新
const state = { count: 0 }
state.count = 1   // ❌ 用了它的组件不会重渲染
```

`Vue.observable()` 把这个普通对象变成响应式的——改了就有反应。

### 基本用法

```js
// store.js — 独立文件
import Vue from 'vue'

export const store = Vue.observable({
  count: 0,
  userName: '张三'
})

export const mutations = {
  increment() { store.count++ },
  setUser(name) { store.userName = name }
}
```

```vue
<!-- 组件 A -->
<template>
  <div>{{ store.count }}</div>       <!-- 0 → 1 → 2... 自动更新！ -->
</template>
<script>
import { store, mutations } from './store.js'
export default {
  data() { return { store } }        // 把响应式对象放入 data
}
</script>
```

**完整流程：**

```
普通对象 { count: 0 }
  → Vue.observable() 用 Object.defineProperty 包裹每一层
  → 变成响应式对象
  → 放入组件的 data
  → 组件模板用了 count
  → 改了 count → 组件自动重渲染
```

### 这不是 Vuex 吗？

对，`Vue.observable` 就是 **Vuex 的底层引擎**。Vuex 内部就是用 `Vue.observable`（Vue 2 叫 `new Vue({ data })`）来做响应式的。如果你只需要一个简单的全局状态，不想引入整个 Vuex，可以直接用 `Vue.observable`。

### `Vue.observable` vs Vuex 对比

| | Vue.observable | Vuex |
|------|------|------|
| 复杂度 | 极简，一个文件搞定 | 完整的状态管理框架 |
| 开发工具 | 无 Devtools 支持 | Vue Devtools 可追踪 |
| 规范约束 | 你自己定 | mutation/action/getter 严格分工 |
| 适用场景 | 小型应用、简单跨组件共享 | 中大型应用、团队协作 |
| 本项目 | 未使用（有 Vuex 了） | ✅ 全局使用 |

### 实战示例：跨组件共享用户信息

```js
// store/userStore.js
import Vue from 'vue'

export const userStore = Vue.observable({
  currentUser: null,
  isLoggedIn: false
})

export function login(user) {
  userStore.currentUser = user
  userStore.isLoggedIn = true
}

export function logout() {
  userStore.currentUser = null
  userStore.isLoggedIn = false
}
```

```vue
<!-- 任意组件直接 import 使用 -->
<script>
import { userStore, login } from '@/store/userStore'
export default {
  data() { return { user: userStore } },    // 放入 data 才能在模板中直接用
  methods: {
    handleLogin() { login({ name: '张三' }) }
  }
}
</script>
```

> Vue 3 中 `Vue.observable` 被 `reactive()` 替代，概念完全一样。

---

## 八、一句话区分

> `data` 存数据，`computed` 算数据（有缓存），`watch` 看数据变化做别的事。
