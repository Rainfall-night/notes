# 单文件组件 (.vue)

> 基于 MES 前端项目 `STwebsiteFrontEnd_V1` 的实际代码

---

## 一、三段式结构

```vue
<template>        ← HTML 骨架，构建时编译成 render 函数
  <div>{{ message }}</div>
</template>

<script>          ← JS 逻辑
export default {
  data() { return { message: 'Hello' } },
  methods: {},
  computed: {},
  mounted() {}
}
</script>

<style scoped>     ← CSS 样式
.el-dialog { width: 90%; }
</style>
```

一个 `.vue` 文件 = 一个自包含的 UI 单元，HTML/JS/CSS 封装在一起。

## 二、scoped 样式隔离

```html
<!-- 不加 scoped：全局生效 -->
<style>
.el-dialog { width: 90%; }
</style>

<!-- 加了 scoped：只作用本组件 -->
<style scoped>
.el-dialog { width: 90%; }
/* 编译后：.el-dialog[data-v-abc123] { width: 90%; } */
</style>
```

Vue 自动给组件内的元素加 `data-v-xxx` 属性实现样式隔离。

### 本项目中的用法

```vue
<style lang="scss" scoped>    <!-- 组件私有，用 SCSS 语法 -->
<style>                       <!-- 全局样式，跨页面统一 -->
  .el-table .warning-row { background: oldlace; }
  .el-table .overdue-row { color: #FF7F00; }
</style>
```

> ⚠️ 项目中 52 个 procedure 页面都重复写了相同的全局样式。由于没有 `scoped`，只需在一个地方定义就够了。

## 三、lang="scss"

表示用 SCSS 语法，`vue-loader` 自动调用 `sass-loader` 编译：

```scss
.el-dialog {
  width: 90%;
  .centerLabel {           // SCSS 嵌套
    margin-bottom: 10px;
  }
}
// 编译后：.el-dialog .centerLabel { margin-bottom: 10px; }
```

## 四、export default 组件选项完整清单

```js
export default {
  // ═══ 标识 ═══
  name: 'MyComponent',           // 组件名（devtools 中显示）

  // ═══ 数据 ═══
  data() { return {} },          // 响应式数据（必须是函数）
  props: {},                     // 父组件传入的属性
  propsData: {},                 // （测试用）
  computed: {},                  // 计算属性（有缓存）
  methods: {},                   // 方法
  watch: {},                     // 监听器

  // ═══ DOM ═══
  el: '#app',                    // 挂载点（仅根实例）
  template: '<div>...</div>',    // 模板字符串（极少用）
  render(h) { return h('div') }, // 渲染函数

  // ═══ 生命周期 ═══
  beforeCreate() {},             // 实例刚初始化
  created() {},                  // data 可访问，DOM 未挂载
  beforeMount() {},              // 挂载前
  mounted() {},                  // DOM 挂载完成
  beforeUpdate() {},             // 数据更新前
  updated() {},                  // 数据更新后
  activated() {},                // keep-alive 激活时
  deactivated() {},              // keep-alive 停用时
  beforeDestroy() {},            // 销毁前
  destroyed() {},                // 销毁后
  errorCaptured() {},            // 捕获子组件错误

  // 详见 [[05-组件生命周期]]

  // ═══ 资源 ═══
  components: {},                // 注册子组件
  directives: {},                // 局部指令
  filters: {},                   // 局部过滤器

  // ═══ 组合 ═══
  mixins: [],                    // 混入
  extends: {},                   // 继承
  provide() { return {} },       // 向后代注入
  inject: [],                    // 接收祖先注入

  // ═══ 其他 ═══
  model: {},                     // v-model 自定义
  inheritAttrs: true,            // 是否继承未被 props 声明的属性
  comments: false,               // 是否保留 HTML 注释
}
```

### 本项目实际使用情况

| 选项         | 本项目                      |
| ------------ |:--------------------------- |
| `name`       | ✅ 大部分页面都有           |
| `components` | ✅ 注册子组件               |
| `directives` | ✅ `permission`             |
| `filters`    | ✅ `statusFilter`           |
| `data`       | ✅ 大量使用                 |
| `props`      | ✅ checkin/checkout 子组件  |
| `computed`   | ✅ `rules`、`pickerOptions` |
| `watch`      | ✅ 搜索条件同步             |
| `methods`    | ✅ 大量使用                 |
| `mounted`    | ✅ `fetchData()`            |
| `activated`  | ✅ keep-alive 页面          |
| `mixins`     | ✅ `ResizeHandler`          |
| `render`     | ✅ `Item.vue` 功能组件      |

## 五、本项目实际示例

```vue
<template>
  <div class="app-container">
    <el-form :model="queryParams">
      <el-input v-model="queryParams.searchText" @keyup.enter="handleSearch" />
    </el-form>
    <el-table :data="listData" :row-class-name="tableRowClassName">
      <el-table-column :width="flexColumnWidth('ID', listData, 5)" />
    </el-table>
    <pagination :total="totalCount" />
  </div>
</template>

<script>
export default {
  data() {
    return { queryParams: { pageIndex: 1, pageSize: 50 }, listData: [], totalCount: 0 }
  },
  mounted() { this.fetchData() },
  methods: {
    fetchData() {
      getList(this.queryParams).then(res => {
        this.listData = res.Data.Items
        this.totalCount = res.Data.TotalCount
      })
    }
  }
}
</script>
```

## 六、组件命名规则

Vue 注册组件时，PascalCase 和 kebab-case **自动互认**，无需手动声明别名。

```js
// 注册：PascalCase
components: { SidebarItem }

// 模板中使用：kebab-case — 自动匹配！
<sidebar-item />
```

### 为什么

HTML 不区分大小写，`<SidebarItem>` 在浏览器眼里等于 `<sidebaritem>`，无法解析。所以 Vue 自动做了双向转换：

| 注册写法 | 模板中可用 |
|------|------|
| `SidebarItem` | `<sidebar-item>` 或 `<SidebarItem>` |
| `MyComponent` | `<my-component>` 或 `<MyComponent>` |
| `checkin-dialog` | `<checkin-dialog>` 或 `<CheckinDialog>` |

### 本项目中

```js
// Sidebar/index.vue
components: { SidebarItem, Logo }   // ← PascalCase 注册
```

```vue
<sidebar-item />    ← kebab-case 使用，自动匹配
<logo />            ← 小写也可以
```

> 这是 Vue 内置规则，不是别名。所有的 `components` 注册都遵循这个约定。
