# 自定义指令

> 基于 MES 前端项目 `STwebsiteFrontEnd_V1` 的实际代码

---

## 一、什么是自定义指令

Vue 允许你注册自己的 `v-xxx` 指令，用于**直接操作 DOM**。区别于组件的生命周期钩子，指令钩子是在 DOM 层面工作的。

## 二、Vue 指令的钩子

| 钩子 | 触发时机 |
|------|----------|
| `bind` | 指令第一次绑定到元素时（只一次） |
| `inserted` | 元素**插入父节点**时 |
| `update` | 组件 VNode 更新时 |
| `componentUpdated` | 组件及子组件更新**后** |
| `unbind` | 指令解绑时（只一次） |

## 三、本项目示例：v-permission（按钮级权限控制）

### 定义（permission.js 尾部）

```js
export default {
  inserted(el, binding, vnode) {
    const { value } = binding              // v-permission="['Procedure_TEST_LIV']" 中的数组
    const roles = store.getters.roles      // 用户角色列表

    const hasPermission = roles.some(role =>
      value.includes(role)                 // 用户角色中是否有匹配的？
    )

    if (!hasPermission) {
      el.parentNode.removeChild(el)        // 没权限 → 从 DOM 中直接移除
    }
  }
}
```

### 注册（main.js）

```js
import permission from '@/permission'
Vue.directive('permission', permission)
```

### 使用（页面模板中）

```vue
<el-button v-permission="['Procedure_TEST_LIV']" @click="handleCheckIn">
  Track In
</el-button>
```

## 四、指令钩子的固定参数

Vue 框架在调用指令钩子时，自动传入以下参数（名字可以改，但位置固定）：

| 参数 | 含义 |
|------|------|
| `el` | 指令所在的真实 DOM 元素 |
| `binding` | 指令绑定信息对象 |
| `vnode` | 虚拟节点（Vue 内部对象） |
| `oldVnode` | 上一个虚拟节点（仅 `update` 钩子有） |

### binding 对象结构（Vue 框架硬编码，不可自定义）

```js
// v-permission="['admin']" 对应的 binding
{
  name:       'permission',              // 指令名（v- 后面的部分）
  value:      ['admin'],                 // JS 求值结果
  expression: "['admin']",               // 原始字符串
  arg:        undefined,                 // v-permission:xxx 中的 xxx
  modifiers:  {},                        // v-permission.mod 中的修饰符
  oldValue:   undefined,                 // 上一个值（仅 update）
}
```

## 五、为什么用 `inserted` 而不是 `bind`

```js
// bind：元素可能还未插入 DOM → el.parentNode 为 null → removeChild 失败
// inserted：元素已在 DOM 中 → el.parentNode 一定存在 → 删除安全
```

## 六、全局指令 vs 局部指令

```js
// 全局（main.js 中注册，所有组件可用）
Vue.directive('permission', { inserted() {} })

// 局部（单组件 directives 选项中注册）
export default {
  directives: {
    permission: { inserted() {} }
  }
}
```

## 七、与组件生命周期的区别

| | 自定义指令 | 组件 |
|------|-----------|------|
| this 指向 | **无 this**（undefined） | 组件实例 |
| 用途 | 操作原始 DOM | 管理数据/逻辑 |
| 参数 | `el, binding, vnode` | data/computed/methods |
