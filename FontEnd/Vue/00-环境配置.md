# FNM + NodeJS
1. 建目录
	```
mkdir D:\DevelopTools\fnm
mkdir D:\DevelopTools\fnm\npm-global
	```
	
2. 配环境变量（手动操作，不动了）
	```
用户变量: FNM_DIR = D:\DevelopTools\fnm
Path 追加: D:\DevelopTools\fnm
Path 追加: D:\DevelopTools\fnm\npm-global
	```
	
3. 下载 fnm.exe 放到 D:\DevelopTools\fnm

4. 配 PowerShell 自动加载
```
notepad $PROFILE
```
然后在文件末尾追加：
```
fnm env --use-on-cd | Out-String | Invoke-Expression
```

5. 重启终端，装 Node
```
fnm install 14
fnm use 14
fnm default 14
```

6. 再配 npm 全局路径 与淘宝镜像源
	```
npm config set prefix "D:\DevelopTools\fnm\npm-global"
npm config set registry https://registry.npmmirror.com
	```

7. 验证
```
node -v       # → v14.21.3
npm -v        # → 6.x
npm install -g yarn
yarn -v       # → 应有输出
```
