# 模板语法

> 基于 MES 前端项目 `STwebsiteFrontEnd_V1` 的实际代码

---

## 一、插值 `{{ }}` — 显示数据

```vue
<span>{{ scope.row.WorkOrderCode }}</span>
<span>{{ scope.row.TAT.toFixed(1) }}</span>
```

双花括号里写 JS 表达式，Vue 自动把值渲染到那个位置。数据变 → 显示跟着变。

> 这与 [[02-Vue实例与渲染流程#六、虚拟 DOM 与 diff 算法|虚拟 DOM]] 配合：数据变 → render 重新执行 → diff → 只更新变化的 `{{ }}` 位置。

---

## 二、`v-bind` / `:` — 绑定属性

```vue
<el-table :data="listData" :row-class-name="tableRowClassName">
<!-- 等价于 v-bind:data="listData" -->
```

| 写法 | 效果 |
|------|------|
| `width="100"` | 永远是 100（静态） |
| `:width="flexColumnWidth(...)"` | JS 算出来是多少就是多少（动态） |

---

## 三、`v-if` / `v-show` — 条件渲染

```vue
<el-table-column v-if="tableList[0].isTrue" label="ID" />
<pagination v-show="totalCount>0" />
```

| | `v-if` | `v-show` |
|------|------|------|
| 原理 | 创建/销毁 DOM | `display: none` 切换 |
| 初始开销 | 小（不渲染） | 大（始终渲染） |
| 切换开销 | 大（重建 DOM） | 小（只改 CSS） |
| 适用 | 不频繁切换（如列可见性） | 频繁切换（如 loading） |

---

## 四、`v-for` — 循环渲染

```vue
<el-option
  v-for="item in PriorityOption"
  :key="item.value"
  :label="item.label"
  :value="item.value"
/>
```

> ⚠️ `:key` 必须加！否则 [[02-Vue实例与渲染流程#六、虚拟 DOM 与 diff 算法|diff 算法]] 无法高效匹配节点。

---

## 五、`v-model` — 双向绑定

```vue
<el-input v-model="queryParams.searchText" />
```

本质是 `v-bind:value` + `@input` 的语法糖。用户输入和 JS 数据双向同步。

---

## 六、`@` / `v-on` — 事件绑定

```vue
<el-button @click="handleSearch">搜索</el-button>
<el-input @keyup.enter.native="handleSearch" />
<el-table @sort-change="handleSort" />
```

`.native` 修饰符：监听组件根元素的**原生 DOM 事件**。

---

## 七、`slot` / `slot-scope` — 作用域插槽

```vue
<el-table-column label="TAT(小时)">
  <template slot-scope="scope">
    {{ Number(scope.row.TAT).toFixed(1) }}
  </template>
</el-table-column>
```

Element UI 表格通过 `scope.row` 把当前行数据传给你，由你决定怎么渲染。

## 八、本项目语法速查

| 语法 | 简写 | 项目中的实际用法 |
|------|------|------|
| `{{ }}` | - | `{{ scope.row.ID }}` |
| `v-bind` | `:` | `:width="flexColumnWidth('ID', listData, 5)"` |
| `v-if` | - | `v-if="tableList[0].isTrue"` |
| `v-show` | - | `v-show="totalCount>0"` |
| `v-for` | - | `v-for="item in PriorityOption" :key="item.value"` |
| `v-model` | - | `v-model="queryParams.searchText"` |
| `v-on` | `@` | `@click="handleSearch"` |

## 九、动态组件 `<component :is>` — 运行时切换组件

Vue 内置的占位组件。`:is` 指向哪个组件名，它就渲染哪个组件。

```vue
<template>
  <div>
    <el-button @click="currentTab = 'TabA'">Tab A</el-button>
    <el-button @click="currentTab = 'TabB'">Tab B</el-button>

    <component :is="currentTab" />
    <!-- currentTab='TabA' → <TabA />, currentTab='TabB' → <TabB /> -->
  </div>
</template>

<script>
import TabA from './TabA.vue'
import TabB from './TabB.vue'
export default {
  components: { TabA, TabB },
  data() { return { currentTab: 'TabA' } }
}
</script>
```

**切换时默认销毁旧组件、创建新组件**——旧组件走 `destroyed`，新组件走 `created`/`mounted`。

**配合 `<keep-alive>` 缓存以免反复销毁重建：**

```vue
<keep-alive>
  <component :is="currentTab" />
</keep-alive>
<!-- 切走再切回来 → 组件不销毁，走 activated/deactivated -->
```

> `:is` 可以是已注册的组件名字符串、组件选项对象、或异步组件。

## 十、`v-once` / `v-pre` / `v-cloak` — 渲染控制指令

### `v-once` — 只渲染一次，之后不再更新

```vue
<span v-once>初始值：{{ initialValue }}</span>
<!-- initialValue 以后变了，这里永远显示初始值 -->
```

> 适合渲染后绝对不会变的内容（页面标题、静态配置），节省追踪开销。

### `v-pre` — 跳过编译，原样输出

```vue
<pre v-pre>{{ 这里不会被编译，直接显示花括号 }}</pre>
```

> 适合大量静态文本、展示原始模板代码的文档页面。

### `v-cloak` — 隐藏未编译的模板

页面加载瞬间用户可能看到原始 `{{ }}`（闪烁）。`v-cloak` 配合 CSS 解决：

```css
[v-cloak] { display: none }
```
```vue
<div v-cloak>{{ message }}</div>
<!-- Vue 编译完成后自动移除 v-cloak 属性 → 显示内容 -->
```

> 现代 SPA 项目基本不遇到闪烁问题，这是历史遗留方案，但面试可能问。

## 十一、`<transition>` / `<transition-group>` — 过渡动画

### 基本用法

```vue
<transition name="fade">
  <div v-if="visible">淡入淡出的内容</div>
</transition>
```

Vue 自动在合适时机添加/移除 CSS 类：

```
进入：fade-enter → fade-enter-active → fade-enter-to
离开：fade-leave → fade-leave-active → fade-leave-to
```

```css
.fade-enter, .fade-leave-to { opacity: 0 }
.fade-enter-active, .fade-leave-active { transition: opacity 0.5s }
```

### 实战场景

```vue
<!-- 弹窗动画 -->
<transition name="el-fade-in">
  <el-dialog :visible.sync="dialogVisible">...</el-dialog>
</transition>

<!-- 列表动画 -->
<transition-group name="list" tag="ul">
  <li v-for="item in items" :key="item.id">{{ item.name }}</li>
</transition-group>
```

> Element UI 组件内部自带过渡动画。自定义组件才需要手动加 `<transition>`。
