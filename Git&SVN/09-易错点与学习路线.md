# 09 · 易错点与学习路线

> 相关笔记:[[00-总览-MOC]] · [[03-文件生命周期与提交]] · [[04-历史对比与撤销]] · [[05-分支合并与标签]] · [[06-远程协作与忽略]]

## 一、易错点总结(实战避坑)

| # | 坑 | 说明 | 相关 |
|---|---|---|---|
| 1 | SVN 忘 `svn add` 新文件 | 新文件不 add,commit 不包含它 | [[03-文件生命周期与提交]] |
| 2 | 想在 SVN 用 `git push` | SVN 没有 push,commit 就是上服务器 | [[03-文件生命周期与提交]] |
| 3 | SVN 离线提交 | 不可能,必须联网 | [[01-核心概念与架构]] |
| 4 | 以为 SVN 能 reset 抹历史 | 不能,只能反向 merge 再提交 | [[04-历史对比与撤销]] |
| 5 | `git reset --hard` 乱用 | 危险,丢未提交改动,先 stash 或备份 | [[04-历史对比与撤销]] |
| 6 | SVN 频繁建分支 | 分支是目录拷贝,慢且占空间,小改动走主线 | [[05-分支合并与标签]] |
| 7 | 不勤 `svn update` | 越晚更新冲突概率越高 | [[05-分支合并与标签]] |
| 8 | SVN revert 后后悔 | 无 reflog,不可恢复 | [[04-历史对比与撤销]] |
| 9 | `git push -f` 乱用 | 覆盖远端历史,团队慎用 | [[06-远程协作与忽略]] |
| 10 | 忽略规则搞混 | Git 用 `.gitignore`,SVN 用 `svn:ignore` | [[06-远程协作与忽略]] |

## 二、核心循环(背下来)

```bash
# Git
clone → pull → 改 → add → commit → push

# SVN
checkout → update → 改 → (add 新文件) → commit
```

## 三、学习路线建议

1. **先动手**:用测试仓库练,或在公司项目开临时分支
2. **记牢核心循环**(见上)
3. **图形工具辅助**:SVN 用 TortoiseSVN(右键可视化 diff/merge);Git 用 VS Code 源码管理面板
4. **遇到冲突别慌**:先 `status` 看冲突文件,再用图形合并工具解决
5. **对照查表**:需要时翻 [[08-命令速查]]
