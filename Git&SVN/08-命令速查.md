# 08 · 命令速查

> 相关笔记:[[00-总览-MOC]] · 全部章节的"常用参数"都汇总在这里

## 一、Git 速查

### 暂存与提交
```bash
git add file / git add . / git add -A   # -A 连删除也暂存
git add 目录                            # 添加整个目录
git add -p                  # 交互分块暂存(只提交部分改动)
git commit -m "msg"
git commit -am "msg"        # 已跟踪文件跳过 add
git commit --amend -m "msg" # 修改上次提交信息
git commit --amend --no-edit  # 追加改动到上次提交
git reset <file>            # 取消暂存(或用 restore --staged)
```

### 分支
```bash
git branch / -v / -a / -r
git branch 名 / git branch -D 名
git checkout -b 名 / git switch -c 名 / git switch - 
git merge 名 / git merge --no-ff 名
git log --graph --oneline --all
```

### 远程
```bash
git remote -v / add origin / add upstream / set-url / remove / rename
git push / git push origin 分支 / git push -u 分支
git push --force(危险) / git push --force-with-lease(安全)
git pull / git pull --rebase
git fetch
git clone -b 分支 url
```

### 撤销与历史
```bash
git restore file / --staged / --source=commit
git checkout -- file
git reset --soft|--mixed|--hard HEAD~1
git revert <哈希>
git commit --amend
git log --oneline / -5 / --author / --grep / --graph
git diff / --cached(=--staged) / HEAD
git blame file
git stash / save / list / pop / apply / drop
git rebase main / --continue / --abort
git cherry-pick <哈希>
git reflog
git tag / git tag -a v1.0 -m "msg" / git push --tags
```

## 二、SVN 速查

### 基本
```bash
svn checkout url [目录]
svn update / svn update -r 120
svn commit -m "msg"
svn add 文件
svn delete 文件
svn move 旧 新
svn status / -q
svn info
svn cleanup
```

### 历史与对比
```bash
svn log / -l 10 / -v / -q / --search "xxx" / <文件>
svn diff / -r 120:125 / --summarize
svn blame file
svn cat -r 120 file.txt
```

### 撤销与回退
```bash
svn revert -R .
svn merge -r 125:120 .
svn update -r 120
```

### 分支/标签/忽略
```bash
svn copy urlA urlB -m "msg"
svn switch url
svn merge url
svn list url
svn propset svn:ignore "bin obj" .
svn propedit svn:ignore .
```

### 其他
```bash
svn lock / svn unlock
svn export url
svnadmin create /路径
```
