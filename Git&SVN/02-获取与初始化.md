# 02 · 获取与初始化项目

> 相关笔记:[[01-核心概念与架构]] · [[03-文件生命周期与提交]] · [[06-远程协作与忽略]]

## 1. 克隆与签出

```bash
# Git
git clone https://github.com/xxx/yyy.git
git clone https://github.com/xxx/yyy.git myfolder
git clone -b develop <url>       # 克隆指定分支
git clone --depth 1 <url>        # 浅克隆(只拉最近一次)

# SVN
svn checkout https://svn.company.com/repo/trunk
svn checkout https://svn.company.com/repo/trunk myfolder
```

> ⚠️ **SVN 没有"分支参数",分支就是 URL 里的路径**。`/trunk`、`/branches/dev` 都是 URL 的一部分。这是和 Git 最大的思维差异。详见 [[05-分支合并与标签]]。

## 2. 初始化与导入

| 操作 | Git | SVN |
|---|---|---|
| 本地初始化 | `git init` | `svnadmin create <repo>`(服务器端) |
| 首次提交到空库 | `git add` + `commit` + `push` | `svn import <目录> <url> -m "msg"` |

```bash
git init                  # 在当前目录初始化
svnadmin create D:\repo   # 服务器上建库(管理员操作)
svn import . https://svn.company.com/repo -m "初始导入"
```

## 3. 日常核心循环(记牢)

```bash
# Git 循环:clone → pull → 改 → add → commit → push
git clone <url>
git pull
# ...改代码...
git add .
git commit -m "说明"
git push

# SVN 循环:checkout → update → 改 → (新文件 add) → commit
svn checkout <url>
svn update
# ...改代码...
svn add 新文件        # 只有新文件需要 add!
svn commit -m "说明"
```
