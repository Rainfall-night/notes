## 1. 数组（定长）

```csharp
int[] nums = new int[5];      // 长度固定 5，不能变
nums[0] = 1;

int[] nums2 = { 1, 2, 3 };    // 直接初始化
int first = nums2[0];         // 下标访问，越界抛 IndexOutOfRangeException
```

- **底层**：内存里一段**连续**的固定长度空间，下标访问是 O(1)（直接算地址）
- **缺点**：长度固定，不能动态增删 → 于是有了 `List<T>`

## 2. List<T>（动态数组，最常用）

### 2.1 基本用法

```csharp
var list = new List<int>();
list.Add(1);            // 追加
list.Remove(1);         // 按值删
list.Contains(2);       // 是否包含
int count = list.Count; // 元素个数
list[0] = 99;           // 下标访问（随机访问 O(1)）
list.Insert(0, 5);      // 中间插入（O(n)，后面元素要后移）
```

### 2.2 底层：内部数组 + 扩容

`List<T>` 内部就是一个 `T[]` 数组，两个概念：

- `Count`：**实际**元素个数
- `Capacity`：**数组容量**（大于等于 Count）

```csharp
var list = new List<int>();       // Capacity = 0
list.Add(1);                       // Capacity 不够 → 扩容到 4
list.Add(2); list.Add(3); list.Add(4);   // 满
list.Add(5);                       // 又满了 → 扩容到 8（翻倍）
```

**扩容机制**：满了就新建**2 倍大**的数组，把旧元素**拷贝**过去，换上新数组。

**性能分析**：

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 下标访问 `list[i]` | O(1) | 数组直接算地址 |
| 尾部 `Add` | **摊销 O(1)** | 平时 O(1)，偶尔扩容 O(n)，平均下来 O(1) |
| 中间 `Insert` | O(n) | 后面元素要整体后移 |
| `Contains` | O(n) | 线性查找 |

> **关键**：`Add` 看起来是"追加"，其实扩容时是"新建数组 + 全量拷贝"。所以如果你**提前知道元素数量**，用 `new List<int>(1000)` 预分配容量，避免反复扩容拷贝。

## 3. Dictionary<K,V>（哈希表）

### 3.1 基本用法

```csharp
var dict = new Dictionary<string, int>();

dict["apple"] = 10;         // ① 赋值（key 存在则覆盖）
dict.Add("banana", 20);     // ② 添加（key 已存在 → 抛异常）

int v = dict["apple"];      // 取值（key 不存在 → 抛 KeyNotFoundException）
bool has = dict.ContainsKey("apple");   // 先判断再取

foreach (var kv in dict) {
    // kv.Key / kv.Value
}
```

**注意 `dict["k"] = v` vs `dict.Add("k", v)`**：
- `dict["k"] = v`：有则覆盖，无则新增
- `dict.Add("k", v)`：已存在就抛异常

### 3.2 底层：双数组 + 哈希桶 + 链表

```csharp
struct Entry {
    int hashCode;   // 键的哈希码（缓存）
    int next;       // 同桶链表里下一个 entry 的下标（-1 = 没有）
    TKey key;
    TValue value;
}

int[] buckets;      // buckets[桶号] = 该桶链表头在 entries 里的下标
Entry[] entries;    // 所有键值对集中存放
int freeList;       // 空闲 entry 链表（删除后复用）
```

**结构示意**（"apple"/"banana"/"cherry" 哈希碰撞到桶 0，头插法）：

```
buckets[0] = 2     ← 桶 0 的链表头是 entries[2]（最后插入的 cherry）

entries：
  下标 0: { hash, next = -1, key = "apple",  value = 10 }
  下标 1: { hash, next = 0,  key = "banana", value = 20 }
  下标 2: { hash, next = 1,  key = "cherry", value = 30 }

遍历：buckets[0]=2 → entries[2] "cherry" (next=1) → entries[1] "banana" (next=0) → entries[0] "apple" (next=-1) 结束
```

**核心记忆**：`buckets` 是"入口"，`next` 是"链条"，`entries` 是"集中存键值对的仓库"。

### 3.3 查找 / 插入 / 删除过程

**查找（TryGetValue）**：

```
① key.GetHashCode() → hashCode
② hashCode % buckets.Length → 桶索引
③ buckets[桶索引] → entry 下标
④ 沿 next 链表遍历：先比 hashCode（快），相等再比 Equals（慢）
⑤ 找到返回，链表走完返回 false
```

**插入（Add）**：

```
① 算 hashCode + 桶索引
② 遍历桶的链表，确认 key 不存在（存在则抛异常）
③ 从 freeList 拿空闲 entry（或追加到 entries 末尾）
④ 填 entry，头插到桶的链表头部（next 指向原链表头）
⑤ count++
```

**删除（Remove）**：

不真的删，而是把 entry 挂到 `freeList` 空闲链表，标记可复用——避免频繁搬移数组。

### 3.4 扩容（Resize）

```
① count 达到阈值触发
② 新建更大的 buckets（容量是质数：3 → 7 → 17 → 37 ...）
③ 重新哈希所有 entry，重新链接
④ 替换数组引用（非原子！→ 并发写会结构撕裂）
```

### 3.5 对比 Java HashMap

| | C# Dictionary | Java HashMap |
|---|---|---|
| 存储结构 | 双数组（buckets + entries 分离） | 单数组（table，槽直接存节点） |
| 链表连接 | int 索引（4 字节） | 对象引用（指针 8 字节） |
| 哈希冲突 | 纯链表 | 链表 + 红黑树（1.8 后） |
| 桶容量 | 质数（3,7,17,37...） | 2 的幂（16,32,64...） |
| 定位桶 | hashCode % buckets.Length（取模） | (n-1) & hash（位与，快） |
| 删除 | freeList 空闲链表复用 | tombstone 标记（1.8） |

**设计差异本质**：
- C# 用"质数 + 纯链表"，靠"连续数组 + int 索引"换缓存友好性，依赖哈希分布均匀
- Java 用"2 的幂 + 红黑树"，靠位运算提速 + 红黑树对抗极端退化

## 4. HashSet<T>（去重集合）

```csharp
var set = new HashSet<int> { 1, 2, 3 };
set.Add(1);            // 已存在，自动忽略
bool has = set.Contains(1);
```

- **底层**：跟 Dictionary 一样是哈希表，只是**只存 key，不存 value**（value 位置存个占位符）
- 适用：去重、快速判断"是否已存在"

## 5. Queue<T> / Stack<T>（队列 / 栈）

```csharp
var queue = new Queue<int>();
queue.Enqueue(1);   // 入队
queue.Dequeue();    // 出队（先进先出 FIFO）

var stack = new Stack<int>();
stack.Push(1);      // 入栈
stack.Pop();        // 出栈（后进先出 LIFO）
```

- **底层**：都是内部数组实现的（循环数组 / 数组 + 栈顶指针）
- `Queue` 先进先出（排队），`Stack` 后进先出（叠盘子）

## 6. LinkedList<T>（真正的链表）

```csharp
var linked = new LinkedList<int>();
linked.AddFirst(1);   // 头插
linked.AddLast(2);    // 尾插
```

- **底层**：真正的双向链表，节点是分散的对象（跟 List 的数组相反）
- 优势：**中间插入/删除 O(1)**（改指针即可）
- 劣势：随机访问 O(n)（要沿指针走）
- 适用：频繁在中间增删、不需要随机访问

## 7. 怎么选（速查）

| 场景 | 用 |
|------|-----|
| 有序列表、随机访问、动态增删 | `List<T>` |
| 按键查找 | `Dictionary<K,V>` |
| 去重 / 判断存在 | `HashSet<T>` |
| 先进先出 | `Queue<T>` |
| 后进先出 | `Stack<T>` |
| 频繁中间增删 | `LinkedList<T>` |

## 8. 集合性能速查

| 集合 | 查找 | 插入尾部 | 插入中间 | 随机访问 |
|------|------|----------|----------|----------|
| 数组 | O(n) | - | - | O(1) |
| List | O(n) | 摊销 O(1) | O(n) | O(1) |
| Dictionary | O(1) | O(1) | - | - |
| HashSet | O(1) | O(1) | - | - |
| Queue/Stack | - | O(1) | - | - |
| LinkedList | O(n) | O(1) | O(1) | O(n) |
