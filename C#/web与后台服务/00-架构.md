# web与后台服务 专题架构

## 命名规则

| 前缀 | 含义 | 内容 |
|---|---|---|
| `0x` | 通用 | 两个框架共享的基础设施（DI、配置、日志、并发、异常） |
| `1x` | HostedService 专属 | 后台服务（Worker Service） |
| `2x` | ASP.NET Core 专属 | Web 应用 |
